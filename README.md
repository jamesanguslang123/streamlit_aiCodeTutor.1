# CODETUTOR – AI Code Explainer

**Version:** 1.0

## Overview
CODETUTOR is a Python-based AI coding assistant designed to help users understand Python errors and learn how to fix them.

The project uses an AI language model through Ollama to analyse programming errors, explain why they occur, and suggest possible solutions.

## Features
- Accepts Python errors from the user.
- Uses an AI model to analyse the provided error.
- Explains what the error means in understandable language.
- Identifies potential causes.
- Suggests ways to fix the problem.
- Provides example corrections to help users learn.

## Technologies Used
- Python
- Ollama
- Large Language Models (LLMs)

## What I Learned
Through this project, I explored:

- Sending prompts and receiving AI-generated responses.
- Working with external Python libraries.
- Understanding how AI can be integrated into practical software applications.
